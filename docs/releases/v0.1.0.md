# v0.1.0: first open-source release

An advisory, **read-only-by-default** AI management office for a small company, built on Claude Code. Name your company once and give it context; a Chief of Staff and six specialists work from it.

## Highlights
- **Name and describe your company in two minutes.** `python3 scripts/init_company.py` writes `company/profile.json` and renders `CLAUDE.md`, `company/facts/` and `records/sources.md`. It refuses secrets and identifier-like input.
- **Chief of Staff plus six specialists:** Company Secretary, Chartered Accountant, CFO, CTO, Product Manager, Marketing & Growth, with seven workflows (`/daily-brief`, `/weekly-review`, `/monthly-business-review`, `/compliance-check`, `/financial-review`, `/technology-review`, `/decision-review`).
- **Approval guard.** The AI drafts and recommends; you decide and act. The guard blocks pushes, deploys, sends, secret reads and identifier-like content.
- **Optional local web app** (Next.js): dashboard, AI team, live office view, conversations, tasks, approvals, reports and connector health. Your company name shows in the sidebar. macOS launcher included.
- **Connect your tools, optionally:** Google Drive, Gmail, Vercel, Railway and others, read-only. See the README.
- **CI:** `tests/validate.py` plus web type-check and tests on every push.

## Get started
```bash
git clone https://github.com/arunmenon1807/ai-management-office.git my-office && cd my-office
python3 scripts/init_company.py
python3 tests/validate.py
```
Then open the folder in Claude Code and read `docs/setup.md`. To see the UI: `cd apps/web && npm install && npm run dev`.

## Known limitations
- The Company Secretary and Chartered Accountant specialists default to **Indian law** (GST, ROC/MCA, TDS). Other countries need adaptation: see `docs/localising.md`.
- The regex guard is not a sandbox: see `docs/permission-model.md`.
- The desktop launcher is macOS only.
- Not professional advice: statutory, tax and legal matters are confirmed by your own professionals.
